# Submission

Provenance Engine is a reusable provenance and evidence-history primitive for decentralized applications that need trustworthy external-state verification.

It separates non-deterministic observation and interpretation from deterministic state transitions. It records evidence lineage, relation classifications, consensus-gated verification, contradictions, freshness, and a portable provenance passport. Its optional bounty escrow uses payable writes, `gl.message.value` as the ledger source of truth, and a single checks-effects-interactions payout path.
